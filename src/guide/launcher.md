# KMod Launcher

KMod Launcher 是加载器的安装器和模组管理器，有 Windows 和 Android 两个版本。到 [Releases](https://github.com/CCB-TEAM/KMod-Launcher/releases) 下载。

| 文件 | 说明 |
|---|---|
| `KMod-Launcher-*-windows-x64.exe` | Windows 10 / 11，单文件，直接运行（需要系统的 WebView2） |
| `KMod-Launcher-*-android-arm64.apk` | Android 8 及以上，64 位 ARM |

## 第一次启动

启动引导依次让你选主题、决定是否使用 GitHub 代理（预设 `gh-proxy.com`、`gh-proxy.org`，也可以自己填）。Android 版还有一步授权，缺一项都无法使用启动器：「所有文件访问」（Android 10 及以下是存储权限），以及部分国产系统单独控制的「获取应用列表」（安装器靠它找到游戏）。设置页的「重新查看启动引导」可以再看一遍。

Android 版以沉浸模式运行，隐藏状态栏和导航栏；从屏幕边缘滑动可以临时唤出。

## 更新启动器

启动时检查启动器有没有新版本，设置页也可以手动「检查更新」。点「更新」后下载并按 GitHub 给出的 SHA-256 校验：Windows 版替换程序后自动重启；Android 版交给系统安装器（第一次要允许启动器安装应用）。如果只能经代理取得版本信息，无法核对文件，启动器只提供发布页链接。1.1.0 及更早的版本没有这个功能，需要手动下载一次。

## 安装加载器

- **Windows**：启动器在 Steam 库里找 KARDS（也可以手动选目录），在「加载器」页安装、更新或卸载，可以选正式版或开发版。下载线路可选直连或 gh-proxy.com。
- **Android**：在「安装器」页选 KARDS，启动器把内置的加载器注入游戏并安装。注意事项和[安装器](installer.md)相同：签名会改变，必须先卸载原版。管理模组需要在系统设置里允许「所有文件访问」。

## 发现

「发现」页列出社区模组，可以搜索、按类型筛选和排序。卡片上显示下载量和 GitHub 星标数，点星标跳到模组仓库（在那里点星）。默认只显示和当前加载器、游戏版本兼容的模组。下载的文件按索引里的 SHA-256 校验，装好后自动启用，下次启动游戏时生效。

> [!WARNING]
> 模组是自动收录的，没有人工审核。原生 C++ 模组能在游戏进程里执行任意代码，每次安装或更新前启动器都会弹出警告。只安装你信任的作者发布的模组。

模组列表来自 [kmod-index](https://github.com/CCB-TEAM/kmod-index)（格式见[模组索引 API](index-api.md)）。在设置里可以填别的索引地址，每行一个。

## 模组

启用、停用、删除模组，安装本地的 `.kmod` 和 `.pak` 文件。刷新按钮重新读取列表并检查更新：已安装的模组在[模组索引](index-api.md)里有能在这台设备上运行的新版本时，标出新版本号，可以单独「更新」或「全部更新」。

「Pak」分类按**加载顺序**排列，用上移、下移调整：越靠下优先级越高，几个 pak 改了同一个资源时以下面的为准。在游戏关闭时调整，下次启动游戏生效。

- Android：顺序保存在 `kmod/pak-order.txt`，加载器按它挂载 `kmod/paks`（需要加载器 0.4.1 以上）。
- 电脑：pak 由游戏自己从 `Content\Paks` 挂载，优先级取决于文件名（以 `_<n>_P.pak` 结尾的优先级是 `(n+1)×100` 加目录的基础优先级）。所以调整顺序会把文件改名为 `原名.kmod_<序号>_P.pak`，例如 `X_P.pak` → `X_P.kmod_03_P.pak`，`.utoc` / `.ucas` / `.sig` 一起改。列表里仍显示原名；模组更新时覆盖改过名的文件，顺序不变（游戏内安装模组更新需要 Windows 加载器 0.4.1 以上）。

带 pak 的模组包会把 pak 装进常规目录；覆盖或删除 pak 之前会列出文件让你确认，删除模组时询问是否一起删除它的 pak，见[模组包里的 Pak](../mod-format/paks.md)。

## 网络

设置里可以填 HTTP / SOCKS5 代理，以及 GitHub 代理前缀（例如 `https://gh-proxy.com`）。版本列表和索引先直连，失败时才经过前缀代理。

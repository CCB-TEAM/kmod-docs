
# 模组环境

每个模组的 `main.lua` 里直接可用：

| 名字 | 说明 |
|---|---|
| [`Mod`](mod.md) | 模组信息 |
| [`Log`](log.md) | 日志 |
| [`Settings`](settings.md) | 用户设置 |
| [`Lang`](lang.md) | 本地化 |
| [`Console`](../../console/register.md) | 注册控制台指令 |
| [`require`](require.md) | 加载本模组内的 Lua 文件 |
| [`kmod`](kmod.md) | 加载器信息 |
| `print(...)` | 等价于 `Log.info` |
